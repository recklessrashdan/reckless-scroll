# Stage modes

Pick one per page. Each mode forbids something the others rely on, which is what keeps two builds from drifting into the same page.

| Mode | How it works | It forbids |
|---|---|---|
| **Pinned story** | A few tall stages. The screen stays put while headlines assemble and copy cues in. | Horizontal movement, full-bleed video |
| **Rail** | Vertical scroll pans a horizontal track of panels. Good for a sequence of proof. | Long pinned paragraphs, centred hero text |
| **Scrub film** | A canvas plays frames under the wheel (`data-rs-frames`). Copy overlays the film. | More than one other mode in the same act, heavy text |
| **Type takeover** | Oversized type is the image. Words move, crop and invert. No photography needed. | Stock imagery, card layouts |
| **Layer drift** | Layered cutouts move at different rates, depth from overlap and scale. | Flat colour grounds, hard cuts |

## Navigation options
Minimal top bar, no nav (scroll only), side index of act names, progress line only, or a persistent bottom caption. Choose one and record it.
